# Bounce Beyond

## Build a Modern Jumping Castle Rental Website

Create a modern, fun, professional, mobile-responsive website for a jumping castle hiring/rental business that provides jumping castles for birthdays, children's parties, school events, family gatherings, celebrations, and other events.

The business currently has **6 jumping castles available for hire**, but the website architecture must be designed so that additional castles can easily be added in the future.

The website should feel **fun, colourful, exciting, trustworthy, family-friendly, and professional**, while still looking polished enough for parents and event organisers to confidently make a booking.

## Main Business Concept

The business rents out jumping castles for events.

A major unique selling point is that the business can **customise the jumping castle design according to the customer's birthday party theme**.

For example:

- Princess theme

- Superhero theme

- Unicorn theme

- Cars/racing theme

- Safari/jungle theme

- Football/sports theme

- Mermaid theme

- Space theme

- Dinosaur theme

- Barbie-inspired pink theme

- Custom colours and decorations

Customers should be able to browse the available jumping castles and also request a **customised design based on their event theme**.

The website should make it clear that customers can either:

1. Hire one of the existing jumping castle designs, OR

2. Request a customised design.

## IMPORTANT REQUIREMENTS

1. This is a **customer-facing website only**.

2. **Do NOT create an admin dashboard.**

3. **Do NOT create admin pages.**

4. **Do NOT create admin login functionality.**

5. The business currently has exactly **6 jumping castles**.

6. Make the architecture scalable so more castles can be added later.

7. Custom jumping castle designs must be a major feature of the website.

8. Use reusable components.

9. Use realistic placeholder content and images until the real business information is provided.

10. Make it easy to replace all placeholder images, castle information, contact details and prices.

11. Booking requests should not automatically be treated as confirmed bookings.

12. Prioritise a beautiful, professional, mobile-friendly user experience.

13. The website should make parents immediately understand what the business offers and how to hire a jumping castle.

14. The primary conversion goal is getting customers to **request a booking or custom design**.

Build the website as a polished, production-quality jumping castle rental website rather than a basic template.
